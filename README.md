# Convene - Event Management Platform (Frontend)

Convene is a modern Event Management Platform single-page application built with HTML5, CSS3, and JavaScript.

## Features
- **Dashboard**: Live platform statistics overview.
- **Events List**: Browse, search, and filter events.
- **Event Details**: Detailed event page, remaining seats indicator, attendee list, and registration form.
- **Create & Edit Event**: Intuitive event setup and editing form.

## Tech Stack
- Frontend: Vanilla JavaScript (SPA), HTML5, Vanilla CSS
- Backend REST API Integration: Node.js, Express, MongoDB (separate backend repo)
